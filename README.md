## 🧾 Descripción del proyecto

Este proyecto simula la gestión de una **biblioteca** que administra libros y socios lectores. Fue desarrollado aplicando los principios de la **Programación Orientada a Objetos (POO)**, haciendo uso de **herencia**, manejo de **excepciones**, y siguiendo buenas prácticas de diseño con un **diagrama UML** de clases.

---

## 🛠️ Funcionalidades principales

El sistema permite realizar las siguientes operaciones mediante un menú interactivo:

### 📘 Libros
- Agregar un nuevo libro a la biblioteca (el sistema asigna un código automáticamente).
- Eliminar un libro (solo si no está prestado).
- Listar todos los libros de la biblioteca.
- Listar solo los libros actualmente prestados.

### 👤 Socios
- Dar de alta un socio lector o lector de sala.
- Dar de baja un socio.
- Listar todos los socios registrados.

### 🔄 Préstamos
- Prestar un libro a un socio lector (solo si no tiene otro en préstamo).
- Prestar uno o varios libros a un lector de sala.
- Devolver un libro.

### ⚠️ Manejo de errores
- Se lanza una excepción si:
  - El libro ya está prestado.
  - El socio lector ya tiene otro libro en préstamo.
  - El lector de sala intenta pedir un libro ya prestado.
